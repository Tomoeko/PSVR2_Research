# PSVR2 Research

Source tools for PSVR2: `psvr2_krw_c`, Stage1, Stage3, `rmmod_helper`,
`open_vrhmd`, and the native build system. Firmware profiles: 01.10 and 06.00.

See [build instructions](docs/build.md) and [device architecture](docs/architecture.md).
Download Sony's dependencies from the
[official PSVR2 open-source page](https://www.playstation.com/en-us/oss/ps-vr2/).
Keep firmware, device data, dependencies, and compiled output local.
Repository code and patches use the [MIT License](LICENSE).

Kernel endpoint-state fix adapted from
[RealSupremium](https://github.com/RealSupremium)'s
[vr2jb change](https://github.com/BnuuySolutions/vr2jb/commit/95a9881e1454).
